## 摘要
基于Mamba的状态空间模型为高分辨率密集预测提供了线性时间的远程建模能力，但顺序状态空间传播会削弱对多类语义分割至关重要的边界敏感和细节敏感响应。我们提出了Reload-Mamba，一种语义分割框架，通过三种分割特定的设计来解决这种传播引起的响应稀释问题：(i) 边界监督的局部细节先验，该先验使用真实边界掩码进行显式训练，以识别需要响应恢复的区域；(ii) 类别不确定性感知的Reload门控，该门控将来自预重载辅助头的逐像素类别熵作为额外的门控信号，这种公式仅在多类密集预测下提供信息；(iii) 层次化的多级Reload机制，该机制在三个解码器层级应用抗稀释细化，并从上到下融合恢复后的表示。基于ConvNeXt-Tiny编码器、多尺度解码器和带有逐像素方向注意力的四方向Mamba扫描，Reload-Mamba在ADE20K上实现了47.9%的单尺度mIoU（多尺度48.9%），在Cityscapes上实现了83.2%的单尺度mIoU。使用ResNet-101 + COCO预训练并在标准DeepLab风格协议下，Reload-Mamba在PASCAL VOC 2012验证集上达到了87.8%的mIoU。控制消融实验表明，三种分割特定的设计各自贡献了超出直接移植先前为二值化提出的抗稀释架构的效果，在ADE20K上相对于直接移植基线累计提升了+2.2 mIoU。

## Abstract
Mamba-based state space models offer linear-time long-range modeling for high-resolution dense prediction, but sequential state-space propagation can attenuate boundary-sensitive and detail-sensitive responses that are critical in multi-class semantic segmentation. We propose Reload-Mamba, a semantic segmentation framework that addresses this propagation-induced response dilution through three segmentation-specific designs: (i) a boundary-supervised local detail prior that is explicitly trained with ground-truth boundary masks to identify regions requiring response restoration; (ii) a class-uncertainty-aware Reload Gate that incorporates per-pixel class entropy from a pre-reload auxiliary head as an additional gating signal, a formulation that is informative only under multi-class dense prediction; and (iii) a hierarchical multi-level Reload mechanism that applies anti-dilution refinement at three decoder levels and fuses the restored representations top-down. Built upon a ConvNeXt-Tiny encoder with a multi-scale decoder and four-directional Mamba scanning with pixel-wise directional attention, Reload-Mamba achieves 47.9% single-scale (48.9% multi-scale) mIoU on ADE20K and 83.2% single-scale mIoU on Cityscapes. With ResNet-101 + COCO pre-training under the standard DeepLab-style protocol, Reload-Mamba reaches 87.8% mIoU on PASCAL VOC 2012 val. Controlled ablations show that each of the three segmentation-specific designs contributes beyond a direct port of the prior anti-dilution architecture proposed for binarization, cumulatively improving over the direct-port baseline by +2.2 mIoU on ADE20K.

# Reload-Mamba: 用于多类语义分割的分层抗稀释状态空间建模 — 详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：Mamba 状态空间模型（SSM）因线性复杂度的长程建模能力，被引入高分辨率密集预测任务（如语义分割）。然而，Mamba 的顺序状态传播机制会导致特征沿扫描路径逐步混合，从而**削弱边界敏感和细节敏感的局部响应**，作者称之为“传播诱导的响应稀释”（propagation-induced response dilution）。
- **核心问题**：这种稀释在多类语义分割中尤其严重，会导致物体边界模糊、细长结构丢失、小物体响应减弱。先前作者在二值化任务中提出的单级抗稀释架构（DeepMine-Mamba）不适合多类分割，原因有三：(1) 需要恢复的区域（边界、细结构等）不能仅从类别概率中唯一识别；(2) 多类场景中，模糊像素集中在语义过渡区，可通过逐像素类别熵来识别，但二值化中熵无信息；(3) 稀释影响不同尺度的语义，单级细化无法同时服务于大区域、中尺度物体和细边界。
- **研究意义**：提出一种专门针对多类语义分割的抗稀释框架，使 Mamba 在保持高效长程建模的同时，恢复被稀释的局部细节，从而提升分割质量。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
在 Mamba 的编码器‑解码器架构中，于三个解码器层级（D2, D3, D4）引入**分层抗稀释细化**，通过三种分割专用的设计来恢复被稀释的响应：
1. **边界监督的局部细节先验**（Boundary-Supervised Detail Prior）
2. **类别不确定性感知的 Reload 门控**（Class-Uncertainty-Aware Reload Gate）
3. **分层多级 Reload 与自上而下融合**（Hierarchical Multi-Level Reload）

### 关键技术细节

#### 整体架构（如图 1）
- **编码器**：ConvNeXt‑Tiny（或 ResNet‑101），输出四层特征 F1–F4。
- **多尺度解码器**：U 形跳跃融合，生成 D2, D3, D4（通道数分别为 96, 128, 192）。
- **Sobel 边缘先验分支**：从输入图像提取水平/垂直梯度，与原始图像拼接，经卷积投影得到 32 通道边界感知特征 E_s。
- **分层 Reload-Mamba 模块**（应用于 D2, D3, D4）：
  - **边界监督局部细节先验**：对每个解码层，用一个小型卷积网预测先验图 P^(l)（经 sigmoid 归一化），用真实边界掩码（从语义标签图中导出，3×3 邻域内存在不同标签则为边界）的降采样版本进行二元交叉熵监督（总先验损失 L_prior 为三层平均）。利用 P^(l) 构造细节感知特征 X^(l)_d = D_l ⊙ P^(l) + 0.3 * D_l ⊙ (1 - P^(l))。
  - **四方向 Mamba 扫描**：对 X^(l)_d 分别进行右、左、下、上四个方向的 Mamba SSM 扫描（各自独立参数），得到 H^(l)_r, H^(l)_l, H^(l)_d, H^(l)_u。然后通过逐像素方向注意力（一个卷积 + softmax 生成四方向权重）加权融合为 M^(l)。
  - **类别不确定性感知 Reload 门控**：
    - 在 M^(l) 上附加一个轻量级**预重载辅助头**，输出初步语义 logits Y^(l)_u，计算逐像素归一化熵 U^(l)（范围 [0,1]），表示分类模糊度。
    - Reload 门输入：原始解码器特征 D_l、传播前后特征差值 |D_l - M^(l)|、类别不确定性 U^(l)。通过一个小型卷积检测器 + sigmoid 得到检测图 I^(l)_d。
    - 用边界先验 P^(l) 调制：̂I^(l)_d = 0.7 * P^(l) ⊙ I^(l)_d。
    - 恢复后特征：D^(l)_m = M^(l) + ̂I^(l)_d ⊙ (D_l - M^(l))。即对稀释严重的区域（高先验、大变化、高不确定性）从原始特征中补充信息，否则信任 Mamba 增强的上下文。
  - **分层多级融合**：三个级恢复特征 D^(2)_m, D^(3)_m, D^(4)_m 通过自上而下的深度可分离卷积融合成最终特征 D_m。

#### 训练目标（复合损失）
总损失 L_total = L_ohem + 0.8*L_lovasz + 0.1*L_bd + 0.4*L_aux + 0.2*L_prior
- L_ohem：在线困难样本挖掘交叉熵（保留 top 85% 困难像素）
- L_lovasz：Lovász‑Softmax 损失，直接优化 IoU
- L_bd：边界加权交叉熵（仅对边界像素计算）
- L_aux：三个预重载辅助头的标准交叉熵深监督
- L_prior：边界先验的二元交叉熵

## 6. 主要结论与发现

1. **Mamba 的顺序传播确实导致响应稀释**，且稀释影响不同层面的语义尺度，单级细化不足以弥补。
2. **三个分割专用设计各自有效且互补**：边界监督先验 (+0.6)、类别不确定性门控 (+0.7)、分层多级 Reload (+0.9)，累计 +2.2 mIoU 优于直接移植二值化抗稀释架构。
3. **Reload-Mamba 在三个数据集上取得有竞争力的结果**：
   - ADE20K: 47.9% SS / 48.9% MS mIoU（51M 参数）
   - Cityscapes: 83.2% SS mIoU
   - PASCAL VOC: 87.8% val mIoU（ResNet‑101 + COCO）
4. **损失函数的组合（OHEM + Lovász + 边界 + 辅助 + 先验）优于单独使用**，其中辅助深监督贡献最大 (+0.9)。
5. **门控组件中，特征差值项最重要**（去掉降 1.1），类别不确定性次之（降 0.5），说明传播前后的变化是最直接的稀释指示器。
6. **四方向扫描显著优于单/双方向**，表明多方向上下文聚合对细节恢复至关重要。

## 8. 不足与局限

- **实验覆盖不完全**：
  - 消融主要在 ADE20K 上，Cityscapes 和 PASCAL VOC 缺乏每组件消融。
  - 未在 Mamba 骨干（如 VMamba、Vim、Spatial‑Mamba 等）上验证本模块的兼容性，仅使用 ConvNeXt‑Tiny，限制了结论的泛化性。
  - PASCAL VOC 的结果依赖于 COCO 预训练和 ResNet‑101，与 ADE20K 的 ConvNeXt‑Tiny 不直接可比，且未报告 test 集（因 test 服务器关闭，只能报 val）。
- **效率分析不够深入**：仅给出总参数量和 FLOPs，未与竞品做详细的延迟、吞吐量对比，也未分析 Mamba 块带来的额外计算开销在实践中的影响。
- **扫描策略固定**：四方向扫描是固定的，未尝试可学习或内容自适应的扫描路径（作者自承局限）。
- **超参数未在大规模搜索中优化**：α=0.7, λ_low=0.3 等仅做小范围灵敏度测试，可能非最优。
- **与最新 SOTA 对比的定位**：论文明确表示不追求 SOTA 竞争，而是做受控研究，因此结果（如 47.9% vs SegMAN 的 52.6%）有差距，读者需理解其研究定位。
- **潜在偏差风险**：边界先验使用了 3×3 邻域标签变化来定义边界，可能对非常细长的结构或标签噪声敏感；不确定性门控依赖于预重载辅助头的质量，若辅助头训练不稳定可能引入误差。
