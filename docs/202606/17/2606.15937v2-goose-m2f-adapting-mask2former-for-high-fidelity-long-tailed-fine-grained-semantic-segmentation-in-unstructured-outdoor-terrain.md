## 摘要
我们提出了GOOSE-M2F，这是Mask2Former在ICRA 2026 GOOSE 2D细粒度语义分割（FGSS）挑战赛中的任务特定适配。GOOSE基准测试涵盖了非结构化户外地形中的64个细粒度类别，具有严重的长尾分布，其中稀有类别每张图像占据不到50个像素。我们通过三个有针对性的贡献扩展了Swin-Large Mask2Former基线：（1）200个对象查询以消除表示饱和；（2）一个结合了ASPP-lite和CBAM双注意力的特征精炼模块（FRM）；（3）一个辅助监督头，为稀有类别提供直接的逐像素梯度。多阶段训练策略结合了分布平衡损失、稀有类别复制粘贴增强、动态IoU感知重加权和EMA。在推理时，一个带有2D高斯核混合和4尺度TTA的密集滑动窗口引擎增加了+10.57%。GOOSE-M2F达到了70.08%的官方复合mIoU（细粒度63.55%，粗粒度76.61%），在GOOSE 2D FGSS排行榜上排名第三。代码和训练好的模型公开在GitHub: https://github.com/Aditya-Lingam-9000/GOOSE-M2F 和 Hugging Face: https://huggingface.co/XYZ9843/GOOSE-M2F。

## Abstract
We present GOOSE-M2F, a task-specific adaptation of Mask2Former for the GOOSE 2D Fine-Grained Semantic Segmentation (FGSS) Challenge at ICRA 2026. The GOOSE benchmark spans 64 fine-grained classes across unstructured outdoor terrain with a severely long-tailed distribution, where rare classes occupy fewer than 50 pixels per image. We extend the Swin-Large Mask2Former baseline with three targeted contributions: (1) 200 object queries to eliminate representational saturation; (2) a Feature Refinement Module (FRM) combining ASPP-lite and CBAM dual-attention; and (3) an Auxiliary Supervision Head that delivers direct per-pixel gradients for rare classes. A multi-stage training strategy pairs Distribution-Balanced loss, Rare-Class Copy-Paste augmentation, dynamic IoU-aware re-weighting, and EMA. At inference, a dense sliding-window engine with 2D Gaussian kernel blending and 4-scale TTA adds +10.57%. GOOSE-M2F achieves 70.08% Official Composite mIoU (63.55% fine, 76.61% coarse), placing 3rd on the GOOSE 2D FGSS leaderboard. Code and trained models are publicly available at GitHub: https://github.com/Aditya-Lingam-9000/GOOSE-M2F and Hugging Face: https://huggingface.co/XYZ9843/GOOSE-M2F.

- **核心问题**：非结构化户外地形中的细粒度语义分割面临严重的长尾分布问题——稀有类别每张图像像素不足50个，导致模型难以学习。同时存在非晶态边界（植被子类连续过渡）和微小结构（电线杆、交通锥等）带来的挑战。
- **研究背景**：现有城市基准（如Cityscapes、ADE20K）无法覆盖野外机器人在森林、雪地、军事地形等场景中所需的细粒度类别。GOOSE 2D FGSS挑战赛（ICRA 2026）提供了64类标注数据，但类别分布极不均衡：主要类别占据>50%像素，稀有类别出现在<1%图像中。
- **整体含义**：需要针对长尾分布和微小目标设计专用方法，在保持预训练大模型能力的同时引入轻量级改进，实现高保真、高精度语义分割。GOOSE-M2F通过扩展查询数量、特征精炼、辅助监督和推理策略，在排行榜上获得第三名（70.08%复合mIoU），验证了推理时策略在长尾户外基准中的巨大潜力。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
基于Mask2Former（Swin-Large骨干）进行三项有针对性的架构修改，结合多阶段长尾训练策略和密集滑动窗口推理，提升稀有类别和微小结构的分割质量。

### 关键技术细节

#### ① 扩展对象查询（Expanded Object Queries）
- 默认Mask2Former使用100个查询，无法覆盖GOOSE的64类+每图15–20个区域。
- 扩展至200个查询：保留原始100个嵌入，新增100个查询初始化为高斯扰动$q_i = q_{i \bmod 100} + \epsilon_i, \epsilon_i \sim \mathcal{N}(0, 0.02^2 I)$。
- 贡献：+2–3%复合mIoU。

#### ② 特征精炼模块（Feature Refinement Module, FRM）
- 位于像素解码器与Transformer解码器之间，解决像素解码器单一尺度（H/4）限制。
- ASPP-lite：并行空洞卷积，扩张率$d \in \{1,3,6,12\}$（各64通道）+全局池化，经$1\times1$卷积融合。$d=1$针对微小结构，$d=3,6$针对中等物体，$d=12$针对大面积区域（如森林），全局池化针对场景上下文。
- CBAM：顺序应用通道注意力和空间注意力（公式(4)(5)），加上残差连接。
- 贡献：+3–4%在植被和地形类别上。

#### ③ 辅助监督头（Auxiliary Supervision Head）
- 稀有类别（<50像素）在二分匹配中常被分配到更大的竞争对手，从主损失几乎得不到梯度。
- 辅助头在H/4分辨率上直接应用逐像素交叉熵（与查询匹配无关），公式：$\mathcal{L}_{\text{aux}} = \text{CE}(\text{Up}(\hat{y}_{\text{aux}}), y; w_{\text{dyn}})$，总损失$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{M2F}} + 0.4\mathcal{L}_{\text{aux}}$。
- 推理时移除该头，不增加VRAM开销。
- 贡献：+5–8%在稀有类别上。

#### ④ 多阶段训练策略
- **分布平衡损失（DB Loss）**：$w_c = (1-\beta)/(1-\beta^{n_c})$，$\beta=0.9999$，稀有类权重最高50倍，裁剪至[0.1, 10.0]。
- **动态IoU感知重加权**：每验证epoch后根据EMA模型的当前IoU更新类别损失权重，$w_c^{(\text{dyn})} = f_{\text{tier}}(\text{IoU}_c)$，将[0%,80%+]映射为[5×,1×]。
- **稀有类复制粘贴（RCCP）**：预提取稀有类裁剪块，以0.85概率合成到训练图像中，使用5×5高斯软掩膜。微小物体额外缩放$\sim \mathcal{U}(1.2,2.5)$。
- **类别感知重复采样（CAS）**：根据图像中最稀有类别的出现频率过采样，$r_c = \min(p_t / f_c, 3.0)$，$t=0.06$，稀有类图像最多重复3次。
- **指数移动平均（EMA）**：$\theta_{\text{EMA}}^{(t)} = 0.9995 \theta_{\text{EMA}}^{(t-1)} + 0.0005 \theta^{(t)}$，验证和提交均使用EMA权重，贡献+1.0–1.5%。
- **多阶段调度**：共8个阶段，AdamW优化器，多项式LR衰减，1000步线性预热，梯度裁剪5.0。每个阶段骨干学习率为解码器的1/5。三个阶段：预热（阶段1–3，骨干$10^{-6}$，解码器$5\times10^{-6}$）→加速（阶段4，10倍LR跳升，骨干$10^{-5}$，解码器$5\times10^{-5}$）→精炼（阶段8，骨干$5\times10^{-6}$，解码器$2.5\times10^{-5}$）。训练设置：裁剪576×1152，有效批大小16（1样本×16梯度累积），标签平滑0.10，FP16混合精度。

#### ⑤ 推理引擎（Inference Engine）
- **密集滑动窗口**：将图像分割为896×896重叠块，步长384（57%重叠），贡献+4–5%。
- **2D高斯核混合**：每个块的logit图乘以高斯核$k(x,y)=\exp\left(-\frac{(x-c_x)^2}{2\sigma_x^2}-\frac{(y-c_y)^2}{2\sigma_y^2}\right)$，$\sigma=0.5c$，消除拼缝伪影，对细长结构（电线、栅栏）尤其有效。
- **4尺度×2翻转TTA**：图像按{0.5×, 0.75×, 1.0×, 1.5×}缩放，结合水平翻转，共8个视图，logit取均值后argmax。1.5×上采样对微小类别特别有效。
- 总TTA提升：59.51% → 70.08%（+10.57%）。

## 6. 论文的主要结论与发现

- **架构改进有效**：200查询缓解查询饱和，FRM增强多尺度特征，辅助头提供直接梯度信号，三者合计提升~9.2%。

- **学习率加速打破前期平台期**：10倍LR跳升从55.6%提升至56.4%，后续阶段稳步提升，证明了精心设计的学习率策略对长尾训练的重要性。
- 最终系统以70.08%复合mIoU获得第三名，与第一名（76.57%）和第二名（75.40%）有差距，但方法轻量、可解释性强。
