## 摘要
视觉语言模型（VLM）在利用文本类别提示生成分割图以提升半监督脊柱分割中伪标签质量方面具有巨大潜力，但尚无研究涉及。尽管前景可观，但缺乏显式约束来确保脊柱类别提示与脊柱单元区域间的一致性，导致多类分割图生成效果不佳。本文提出CPS4，首个利用类别提示增强脊柱伪标签质量的文本引导半监督脊柱分割网络。具体而言，CPS4通过两个训练阶段实现：（i）类别特定一致性约束的VLM预训练阶段：提出token级和像素级注意力损失，优化类别提示与脊柱单元间的一致性，迫使文本类别提示在语义空间中与目标脊柱单元紧密耦合。（ii）类别提示驱动的半监督脊柱分割阶段：利用预训练的视觉-文本编码器，为未标注脊柱图像导出每个类别特定的二值分割图，并将其整合为统一的多类分割图，从而提升半监督脊柱分割网络生成的脊柱伪标签质量。实验结果表明，我们的CPS4在公开脊柱分割数据集上仅使用5%标注数据即可达到80.44%的Dice分数，超越了流行的半监督学习和VLM方法。我们的代码将公开。

## Abstract
Vision Language Model (VLM) has great potential to enhance the quality of pseudo labels in semi-supervised spine segmentation by leveraging textual class prompts to generate segmentation map, but no one has studied it yet. Although promising, it lacks explicit constraints to ensure consistency between spine class prompts and spine unit region, resulting in unsatisfactory performance in multi-class segmentation map generation. In this paper, we propose CPS4, the first text-guided semi-supervised spine segmentation network using class prompts to enhance the quality of spine pseudo labels. Specifically, CPS4 is implemented through two training stages. (i) Class-specific consistency constrained VLM pretraining stage: we propose token- and pixel-level attention loss to optimize the consistency between class prompts and spine units, forcing the textual class prompt to be closely coupled with the target spine unit in the semantic space. (ii) Class Prompt driven semi-supervised spine segmentation stage: using the pretrained vision-text encoder, we derive each class-specific binary segmentation map for the unlabeled spine image and integrate them into an unified multi-class segmentation map, improving the quality of the spine pseudo label generated by the semi-supervised spine segmentation network. Experimental results show that our CPS4 achieves superior spine segmentation performance with Dice of 80.44%, only using 5% labeled data on the public spine segmentation dataset, surpassing popular semi-supervised learning and VLM methods. Our code will be available.

## 1. 核心问题与整体含义

- **研究动机**：脊柱MR图像的多类分割（椎体VB和椎间盘IVD）对于脊柱疾病诊断和手术计划至关重要。然而，像素级标注需要大量专业人力且昂贵，而半监督学习（SSL）可以利用少量标注数据和大量未标注数据缓解标注稀缺问题。但现有SSL方法（如一致性正则化和伪标签）常因生成的伪标签质量低，引入噪声监督，误导学习过程。
- **背景**：视觉语言模型（VLM）通过文本描述学习图像语义信息，可生成类别提示引导的分割图，有潜力改善伪标签质量。但现有VLM缺乏类别提示与对应图像对象之间的一致性显式约束，导致类别间干扰，多类分割图生成性能不佳。
- **核心问题**：如何利用文本类别提示有效提升半监督脊柱分割中伪标签的质量。

## 2. 方法论

- **整体思想**：提出CPS4，一个两阶段训练框架。第一阶段对VLM进行类别特定一致性约束预训练；第二阶段利用预训练的视觉-文本编码器生成类别提示引导的分割图，增强半监督分割网络的伪标签。

### 关键技术细节

#### 阶段1：类别特定一致性约束的VLM预训练
- **Token级注意力损失（\( L_{token} \)）**：对于每个类别提示\( i \)，提取其文本token \( F_{T,i} \) 和图像的patch tokens \( F_I \)，计算两者相似度得到粗注意力图\( A_i \)。将真实二值分割图\( M_i \)下采样并与\( A_i \)尺寸对齐，二值化为\( \tilde{M}_i \)。\( L_{token} \)定义如下：
  \[
  L_{token} = \frac{1}{N}\sum_{i}\left(1 - \frac{\sum_{u \in B_i} A(i,u)}{\sum_{u} A(i,u)}\right)^2
  \]
  其中\( B_i = \{u \in \tilde{M}_i | u=1\} \)，\( N \)为类别数。该损失鼓励注意力激活聚集到目标脊柱单元区域。
- **像素级注意力损失（\( L_{pixel} \)）**：为防止过度聚集到子区域，引入像素级交叉熵损失：
  \[
  L_{pixel} = -\frac{1}{N}\sum_{i}\left[\tilde{M}(i,u)\log A(i,u) + (1-\tilde{M}(i,u))\log(1-A(i,u))\right]
  \]
- **预训练优化目标**：\( \frac{1}{2}(L_{token} + L_{pixel}) \)，优化视觉编码器（ViT）和文本编码器（BioClinicalBERT）。

#### 阶段2：类别提示驱动的半监督分割
- **类别提示分割图生成**：利用预训练编码器，对每个类别\( i \)，计算图像patch tokens与类别token的点积得到注意力图，上采样后使用OTSU自动阈值得到二值分割图\( y_{text}^i \)，将所有类的二值图堆叠得到最终分割图\( y_{text} \)。
- **伪标签生成与半监督训练**：采用Mean Teacher架构（学生网络\( f_{\theta_s} \)，教师网络\( f_{\theta_t} \)，EMA更新）。对于标注图像计算监督损失\( L_{sup} \)，对于未标注图像计算两个半监督损失：
  - \( L_{semi}^{text} \)：学生预测\( y_s^u \)与类别提示分割图\( y_{text} \)之间的交叉熵。
  - \( L_{semi}^{enhance} \)：学生预测与增强伪标签（教师伪标签\( y_t^u \)与\( y_{text} \)相加）之间的交叉熵。
- **总优化目标**：\( L_{sup} + \frac{1}{2}(L_{semi}^{text} + L_{semi}^{enhance}) \)。
