## 摘要
Segment Anything Model 3 (SAM 3) 为概念提示分割提供了强大的冻结骨干网络，但直接将其应用于开放词汇语义分割（OVSS）效率低下：全分辨率解码通常在整个数据集词汇表上运行，而每个图像仅包含一小部分活跃类别。我们提出ActiveSAM，一个无需训练、零样本推理框架，将SAM 3转变为主动词汇分割器。ActiveSAM首先规范化和扩展类别提示，然后从低分辨率存在预览中估计图像条件的活跃集。仅保留的类别使用冻结的SAM 3解码器通过桶式提示复用进行全分辨率解码。预览阶段仅使用类别存在证据，跳过不必要的分割头计算，而最终阶段应用边缘感知背景校准来抑制低置信度像素。ActiveSAM不需要目标数据集训练、权重更新或预知的类别存在标签。在八个OVSS基准测试中，ActiveSAM改进了无训练开放词汇语义分割的速度-准确率权衡，平均比当前最先进的SegEarth-OV3高出约+1.4 mIoU，同时在大型词汇数据集上运行速度最高提升5.5倍。ActiveSAM在模拟真实世界分布偏移的图像损坏下也表现出最强的鲁棒性，使其非常适合部署在自动驾驶和具身AI等噪声输入领域。代码可在https://github.com/VILA-Lab/ActiveSAM获取。

## Abstract
Segment Anything Model 3 (SAM 3) provides a strong frozen backbone for concept-prompted segmentation, but applying it directly to open-vocabulary semantic segmentation (OVSS) is inefficient: full-resolution decoding is typically run over the entire dataset vocabulary, whereas each image contains only a small active subset of classes. We introduce ActiveSAM, a training-free, zero-shot inference framework that turns SAM 3 into an active-vocabulary segmenter. ActiveSAM first canonicalizes and expands class prompts, then estimates an image-conditioned active set from a low-resolution presence preview. Only the retained classes are decoded at full resolution, using bucketed prompt multiplexing with the frozen SAM 3 decoder. The preview stage uses only class-presence evidence and skips unnecessary segmentation-head computation, while the final stage applies margin-aware background calibration to suppress low-confidence pixels. ActiveSAM requires no target-dataset training, no weight updates, and no oracle class-presence labels. Across eight OVSS benchmarks, ActiveSAM improves the speed-accuracy tradeoff of training-free open-vocabulary semantic segmentation, outperforming the current state-of-the-art SegEarth-OV3 by approximately +1.4 mIoU on average while running up to 5.5x faster on large-vocabulary datasets. ActiveSAM also demonstrates the strongest robustness under image corruption that simulates real-world distribution shift, making it well-suited for deployment in noisy-input domains such as autonomous driving and embodied AI. Code is available at https://github.com/VILA-Lab/ActiveSAM.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：Segment Anything Model 3（SAM 3）在开放词汇语义分割（OVSS）中效率低下。SAM 3 的冻结骨干网络虽然提供强大的空间分割能力，但传统做法是对整个数据集词汇表（可能包含数百个类别）进行全分辨率解码，而单个图像通常只包含少量活跃类别。这造成了严重的计算浪费。
- **背景**：OVSS 要求模型在测试时接受任意词汇表，无需对每个新类别重新训练。现有方法（如基于 CLIP 或 SAM 的方法）要么需要训练，要么在推理时对整个词汇表穷举解码，速度和精度难以兼得。
- **整体含义**：ActiveSAM 提出一种无训练、零样本的推理框架，通过**低分辨率预览**动态筛选每张图像相关的活跃类别，仅对这些类别进行全分辨率解码，从而显著提升推理速度，同时保持甚至提升分割精度。该方法无需任何目标数据集训练、无需更新 SAM 3 权重、无需提前知道图像真实类别存在情况。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 利用 SAM 3 自带的**存在头（presence head）**，在低分辨率（672×672）下快速判断每个类别是否在图像中出现，形成图像特定的**活跃类别集 A(I)**，然后仅对 A(I) 中的类别进行全分辨率（1008×1008）解码。这样，昂贵的解码器调用次数从完整词汇表大小 V 缩减到活跃集大小 |A(I)|（通常远小于 V）。

### 关键技术细节（四个阶段）

1. **上下文提示扩展（Contextual Prompt Expansion, CPE）**
   - 先对原始类别名进行**词汇规范化**（如 `windowpane` → `window pane`）、**词序修复**和**歧义替换**（共 47 条确定性规则，无数据依赖性）。
   - 为每个类别 c 构建增强提示 $\bar{Z}_c$，包含三部分：
     - 规范化后的类别嵌入 $Z_c$
     - 在冻结文本嵌入空间中检索的 $M_s$ 个最近邻类别的投影嵌入 $T_c^{\text{nbr}}$
     - WordNet 中该类别的前 $M_t$ 个上位词（hypernym）的投影嵌入 $T_c^{\text{hyp}}$
   - 提示在数据集阶段一次性构建并缓存，图像推理时复用。

2. **预览驱动的类别选择（Preview-driven Class Selection）**
   - 在低分辨率 $r_p=672$ 下运行冻结 SAM 3 的**存在头**，为所有类别计算存在分数 $q_c = \text{sigmoid}(\rho_c)$，**跳过分割头计算**以降低开销。
   - 设置分位数阈值 $\beta=0.80$，保留存在分数达到阈值的类别，获得初始活跃集 $A_0(I)$。
   - 进一步通过**门控阈值 $V_{\text{gate}}=40$** 限制最大活跃类别数：若 $|A_0(I)| \leq 40$ 则直接保留，否则取 top-40。
   - 对于词汇量 $V \leq 40$ 的小数据集，跳过预览阶段，直接解码全部类别，避免精度损失。

3. **桶式全分辨率解码（Bucketed Full-Resolution Decoding）**
   - 将最终活跃集 $A(I)$ 划分为若干桶，每桶 $K=32$ 个类别。
   - 每桶内，将对应类别提示沿序列维度拼接，与共享的全分辨率图像特征 $X$（由冻结的 SAM 3 图像编码器生成）一同送入**冻结的接地解码器（grounding decoder）**，一次前向得到所有桶内类别的实例分数图和语义分数图。
   - 对每像素取实例和语义分数的最大值进行融合：$S_c(p) = \max\{S_c^{\text{inst}}(p), S_c^{\text{sem}}(p)\}$。
   - 初步预测 $\hat{y}_0(p) = \arg\max_{c \in A(I)} S_c(p)$。

4. **边缘感知背景校准（Margin-Aware Background Calibration, MABC）**
   - 针对含有背景类的数据集，使用 top-1 与 top-2 分数的**边缘信息**进行背景判定。
   - 定义校准置信度：$c_{\text{MABC}}(p) = s_1(p)^{\sqrt{\max(s_1(p)-s_2(p),0)}}$，其中 $s_1, s_2$ 为最高和次高分数。
   - 若 $c_{\text{MABC}}(p) < t^{\gamma}$（$t$ 为数据集的原始背景阈值，$\gamma=1.25$ 为全局指数），则将该像素判定为背景；否则保留初步类别。

### 公式与算法流程（文字说明）
- **CPE 构建**：$\bar{Z}_c = Z_c \parallel T_c^{\text{nbr}} \parallel T_c^{\text{hyp}}$（拼接）
- **存在分数**：$q_c = \text{sigmoid}(\text{PresenceHead}(I_{\text{low}}, \bar{Z}_c))$
- **活跃集**：$A(I) = \{c : q_c \geq \text{Quantile}(\{q_c\}, \beta)\}$ 并应用 Vgate 上限
- **解码**：$G(X, \{\bar{Z}_c : c \in B_j\})$ 对每个桶 $B_j$
- **MABC**：$\hat{y}(p) = \begin{cases} \text{bg}, & c_{\text{MABC}}(p) < t^{1.25} \\ \hat{y}_0(p), & \text{otherwise} \end{cases}$

- **精度**：ActiveSAM 在 8 个基准上平均 mIoU 达到 65.3%，超过 SegEarth-OV3（63.9%）1.4%，超过 SAM 3（57.5%）7.8%。

## 8. 不足与局限

- **召回风险**：低分辨率预览可能漏检微小或严重遮挡的物体，导致该类被过早剪枝，无法在全分辨率阶段恢复。
- **语言与领域局限**：CPE 依赖 WordNet 和基于英语的规范化规则，对医学、工业等专业术语或非英语场景的效果可能受限。
- **安全与伦理风险**：开放词汇分割可能被用于未经授权的监控或细粒度跟踪；在安全关键系统（如自动驾驶）中若漏检关键物体可能引发事故。
- **未探索全分辨率预览**：论文未讨论若使用更高分辨率预览是否能进一步提升 recall 但牺牲速度的折中。
