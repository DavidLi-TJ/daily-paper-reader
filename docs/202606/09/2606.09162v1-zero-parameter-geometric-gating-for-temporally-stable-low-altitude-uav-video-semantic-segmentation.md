## 摘要
低空无人机视频语义分割需要时间一致性，但密集光流在主导航拍图像的平面区域引入空间结构噪声。我们提出一个零参数几何门控，使用RANSAC单应性内点比率在一个16×16空间网格上，在通过语义相似性传播融合之前，将每个区域路由到单应性或光流变形。门控不需要学习参数——仅基于RANSAC统计的中位数阈值二元决策——为冻结骨干网络仅增加211K可训练参数（SSP融合层）。在合成UAVid上，该方法在两个架构（SegFormer-b2和Hiera-S+UPerNet）上相比基础模型实现了+4.24–4.91% mIoU提升。机制诊断显示平面区域中的光流残差在空间上自相关（Moran's I = 0.32, p < 0.001），预测边界不稳定性（Spearman ρ = 0.66），并且刚性化在单应性有效区域中将时间一致性从62%恢复到92%（+29.5pp）。

## Abstract
Video semantic segmentation for low-altitude UAVs requires temporal consistency, yet dense optical flow introduces spatially structured noise in the planar regions that dominate aerial imagery. We propose a zero-parameter geometric gate that uses RANSAC homography inlier ratios on a $16\times16$ spatial grid to route each region to either homography or optical flow warp before fusion via Semantic Similarity Propagation. The gate requires no learned parameters -- only a median-threshold binary decision on RANSAC statistics -- adding only 211K trainable parameters (the SSP fusion layer) to a frozen backbone. On synthetic UAVid, the method achieves +4.24--4.91\% mIoU improvement over base models across two architectures (SegFormer-b2 and Hiera-S+UPerNet). Mechanism diagnostics reveal that flow residuals in planar regions are spatially autocorrelated (Moran's I = 0.32, $p < 0.001$), predict boundary instability (Spearman $ρ= 0.66$), and that rigidification recovers temporal consistency from 62\% to 92\% (+29.5pp) in homography-valid regions.

## 1. 核心问题与整体含义（研究动机和背景）

低空无人机视频语义分割在自主导航、精准农业、城市测绘等关键应用中要求时序一致性（temporal consistency）——相邻帧的预测边界不应闪烁。现有方法（如Deep Feature Flow、NetWarp、Semantic Similarity Propagation）通过光流或单应性将前一帧预测传播到当前帧来提升稳定性。然而，无人机航拍图像以大面积平面区域（道路、建筑、农田）为主，其真实帧间运动可用全局单应性精确描述。密集光流虽然能处理视差和独立运动物体，却在平面区域引入**空间结构化的噪声**（非随机噪声），这反而会破坏边界稳定性。论文通过机制诊断证明：光流与单应性的残差在平面上呈现出显著正空间自相关（Moran's I=0.32），且残差大小直接预测边界不稳定性（Spearman ρ=0.66）。因此核心问题：如何自动、无参数地为每个空间区域选择合适的运动模型（单应性或光流），从而在保持精度的同时恢复时序稳定性。

## 2. 方法论

### 核心思想
提出一个**零参数几何门控**，利用RANSAC单应性拟合质量（内点比率）在16×16空间网格上做二元决策，将每个网格区域路由到单应性变形或光流变形，然后通过语义相似性传播（SSP）融合当前帧预测与传播预测。

### 关键技术细节与流程
1. **稀疏特征匹配**：使用DISK提取关键点，LightGlue进行匹配，RANSAC估计全局单应性H，并标记每个匹配为内点或外点。
2. **网格内点比率**：将图像划分为16×16网格（256个单元），对每个单元c计算内点比率R_c = 单元内内点匹配数 / 单元内总匹配数。
3. **二元门控决策**：门控G_c = 1[R_c ≥ median({R_c})] （中位数阈值自动适应每帧的平面性分布，无需调参）。将16×16门控最近邻上采样至原图分辨率。
4. **双变形融合**：用单应性和光流（RAFT，小模型，8次迭代）分别对前一帧预测q_{t-1}和特征f_{t-1}变形得到q_H、q_F；门控融合：tilde{q}_{t-1} = G ⊙ q_H + (1-G) ⊙ q_F。
5. **SSP融合**：ConvSimBlock计算当前帧特征与传播特征的相似性权重α，最终预测：hat{q}_t = α ⊙ tilde{q}_{t-1} + (1-α) ⊙ q_t。
6. **训练**：仅训练SSP中的ConvSimBlock（211K参数），其余（骨干、解码器、DISK、LightGlue、RANSAC、RAFT）冻结。损失为交叉熵，优化器AdamW，余弦学习率。

## 7. 优点

- **零参数设计**：门控基于RANSAC内点比率和中位数阈值，无需学习参数或超参数调优，简单可靠。
- **架构无关**：可插拔到任意冻结骨干，仅需额外训练一个轻量融合层（211K参数）。
- **机制分析深入**：通过空间自相关、回归分析、刚性化控制等实验，建立了从光流噪声到边界不稳定的因果关系，为方法提供了坚实的理论基础。
- **低额外参数**：视频模型几乎不增加参数，保持效率。
- **诊断实验设计严谨**：Moran's I、Spearman相关、置换检验等统计方法应用恰当。
